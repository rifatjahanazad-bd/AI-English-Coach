NAVIGATION (UI/js/app.js)
-------------------------
.side-tab[data-page] (desktop) + .bottom-nav-item[data-page] (mobile)
  data-page values: chat | practice | test
  pages{} map in initNavigation() must match section ids pageChat/pagePractice/pageTest

----------

test.js: initSpeakingTest(), updateTopicSelection(), updateTimerDisplay()

DATA SHAPES (copy these to add content)
---------------------------------------
Practice subtopic:
  { id, title, desc, question, hint }
  Add to: practiceData.<track>.subtopics in data.js + mirror in practice/<track>.js

Speaking topic:
  { name, emoji, difficulty: 'easy'|'medium'|'hard', prompt }
  Add to: topics[] in data.js (test.js auto-renders card + difficulty pill)

SAFE EDIT RULES
---------------
1. HTML <-> JS: never rename an id without updating getElementById in its init* function.
2. CSS <-> JS: .page.active / .hidden / .selected are logic - style them, don't rename.
3. Add 5th track: copy practice/<track>.js -> register in practiceUI.js modules{} ->
   add card with data-category in #practiceCategoryList -> add entry in practiceData.
4. Add new page: add <section id="pageX"> + side-tab + bottom-nav item with data-page="X" ->
   extend pages{} in app.js -> create css/x.css (import in style.css) ->
   create js/x.js (script tag before app.js, call initX() in boot).
5. Keep script + CSS import order unchanged.
